# Typing Speed Test

A web-based typing speed test application built using Python and Flask.

## Features
- Typing speed (WPM)
- Accuracy calculation
- Result analysis
- Progress graph

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Run the app:
   python app.py
3. Open browser and go to:
   http://127.0.0.1:5000
